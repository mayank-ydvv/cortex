# Cortex — image prompts

Generate these, then drop the files into `public/scenes/` with **exactly these
filenames**. The page reads them automatically; no code change needed.

Palette to keep consistent across all of them:
cream `#fdfbf9` · dew `#f7efe9` · cocoa ink `#2b1a07` · marker orange `#ff6f1e`

Aspect ratio **16:10** for scenes (e.g. 1600×1000 or 2048×1280). They are shown
full-bleed behind a card, so keep the **left third visually calm** — a card sits
there and busy detail behind it makes the text unreadable.
